# LaPompe 0.1.4

- **Firefox's add-on id is now `tontuyau@lapompe`** (it was `lapompe@tontuyau`): addons.mozilla.org keeps a deleted
  add-on's id for good, and LaPompe's first listing there was deleted. A LaPompe installed in Firefox before this
  version is another add-on to Firefox: remove it, install this one and fill in its settings again. Chrome is
  unchanged.
