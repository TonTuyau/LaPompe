# LaPompe 0.1.3

- **"Add channel to TonTuyau" on every channel page**: it was missing on a channel opened by its @handle from
  YouTube itself (a video's channel link, a search result), when the page didn't load anew. LaPompe read the
  channel's id from the page's head, which YouTube's own navigation leaves behind: it then names the @handle, and its
  other links still the first channel opened in the tab. The button is now there at once on an @handle page, and
  LaPompe reads the channel's id from YouTube when it's clicked.
