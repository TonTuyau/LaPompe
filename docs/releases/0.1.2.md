# LaPompe 0.1.2

What Mozilla's review warned about, fixed. The extension does the same as 0.1.1.

- **No `innerHTML`**: Svelte now builds the popup's and the settings' markup with `createElement` instead of a
  template's `innerHTML` (the "Unsafe assignment to innerHTML" warning). The markup was Svelte's own, fixed at build
  time; the DOM is the same.
- **Firefox 140 or later** (142 on Android): the first versions that know `data_collection_permissions`, the data
  declaration Firefox asks of add-ons. Firefox 128 ESR is no longer supported by Mozilla.
